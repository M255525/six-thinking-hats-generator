使用手冊

「六頂思考帽」是愛德華．狄波諾（Edward de Bono）提出的思考方法：把「立場」拆成六種可以輪流切換的角度，避免討論時大家的情緒、事實、風險、創意混在一起互相打架。本工具幫你把問題主題套進固定的提示詞格式，一頂帽子一頂帽子（或六頂依序）產出結構化分析。

六頂帽子代表什麼

帽子核心特性常見問句
白帽客觀事實與數據我們實際掌握了哪些資訊？還缺什麼資料？
紅帽直覺與情緒感受我對這件事的第一直覺、感覺是什麼？
黑帽風險與批判思考哪裡可能出錯？有什麼風險與限制？
黃帽正面價值與可行性好處是什麼？為什麼值得做？
綠帽創意與新可能還有沒有其他做法？能不能換個角度？
藍帽流程掌控與統整目前討論到哪了？下一步該收斂成什麼結論？
實務上常以「藍（開場）→白→紅→黑→黃→綠→藍（收斂）」的順序輪流思考；本工具的「六頂依序」模式固定以「白→紅→黑→黃→綠→藍」各產出一份，方便快速掃過六個角度。

操作步驟

  1. 在「① 問題主題」填入一句話描述的問題或決策，也可以直接套用範例快速開始
  2. 在畫面上方選擇模式：「🎯 單一帽」只看一個角度，「🔄 六頂依序」一次產出六個角度；單一帽模式下點選任一頂帽子即可切換，整頁配色會跟著換成該帽子的顏色
  3. 按「🖊 組成提示詞」，下方會出現組成後的提示詞文字，可按「複製提示詞」貼到任何 AI 對話框自行使用——不需要任何 API 金鑰
  4. 若想直接在本工具取得 AI 產生的分析結果，展開「API 連線設定」填入自己的金鑰，按「🚀 送給 AI 生成分析」；六頂依序模式會依序逐一呼叫並即時顯示進度
  5. AI 若以表格格式回覆，本工具會自動轉成表格顯示；若格式不規則，會直接顯示原始文字——內容一律會移除 `#`、`*` 等 Markdown 格式符號，維持適合直接閱讀
  6. 結果滿意的話，可按「🖨 匯出 PDF」直接列印或存成 PDF；滿意的結果也可以在「④ 已儲存的分析」取名儲存，之後隨時載回來或下載成 .txt 檔

送給 AI 生成分析（選用，需自備 API 金鑰）

組成提示詞之後，可以直接在本工具呼叫你自己的語言模型 API，取得 AI 實際產生的分析內容。

  1. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  2. 按「🚀 送給 AI 生成分析」——若還沒按過「組成提示詞」，會自動先組成一次
  3. 單一帽模式會產生一份結果；六頂依序模式會逐一呼叫六次，任一頂失敗不會中斷其他頂的產生，失敗的那頂會顯示錯誤訊息
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

重新生成規則（六頂依序模式）

六頂依序模式再次按「🚀 送給 AI 生成分析」時，預設不會把六頂全部重打一次：

  • 已經成功、且問題主題沒有變過的帽子，會直接沿用原本的結果，不重打
  • 還沒有結果、上次失敗，或問題主題已經改過的帽子，會自動重新呼叫
  • 若某幾頂已經成功、但你想針對性地重新生成（例如想再試一次某頂的措辭），可以在「🔁 強制重新生成」勾選對應的帽子，按下生成後只有勾選的帽子會重打，其餘沿用原結果；生成完成後勾選會自動清空
「🔁 強制重新生成」只在六頂依序模式顯示；單一帽模式每次按生成本來就只針對目前選中的那一頂，不需要額外勾選。

匯出 PDF

「③ 送給 AI 生成分析」區塊按「🖨 匯出 PDF」，會開啟瀏覽器的列印視窗，選擇「另存為 PDF」即可保存；內容只包含問題主題、模式與 AI 分析結果，畫面上的按鈕、輸入欄位等操作介面不會被印出，每一頁都會加上浮水印。

六頂依序模式若有帽子卡片是收合的，按下「匯出 PDF」時會自動展開，確保六頂帽子的內容都會出現在 PDF 裡。

加入主畫面

頁尾「📲 加入主畫面」可把本工具安裝成 App，往後直接從主畫面／桌面開啟，不用再打開瀏覽器輸入網址。

  • Android／桌面 Chrome、Edge：按下按鈕會直接跳出安裝提示，確認即可
  • iPhone／iPad（Safari）：請點畫面下方的「分享」圖示，選「加入主畫面」
  • Mac 桌面版 Safari（17 以上）：請用選單列「檔案」→「加入 Dock」
畫面已針對手機瀏覽器優化，直接用手機瀏覽器開啟網址也能正常使用，不一定要安裝。

已儲存的分析

「已儲存的分析」是一個留在瀏覽器裡的紀錄清單，按「儲存」不會下載任何檔案，只是把目前主題與產出（含 AI 結果，若有）存成一筆有名字的紀錄。

  1. 在儲存名稱欄位打一個好記的名字，按「儲存」
  2. 清單中每一筆紀錄可以「載入」（會覆蓋目前主題與所選模式）、「下載 .txt」或「刪除」
「儲存」＝存進這台瀏覽器的清單；「下載 .txt」才會真的產生一個檔案到你的下載資料夾。兩者是分開的動作。

隱私說明

  • 你填寫的問題主題、組成的提示詞與「已儲存的分析」清單都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，請自行用「下載 .txt」備份重要內容
  • 複製提示詞後，貼到哪個 AI 服務、該服務如何處理這些文字，就依該服務自己的隱私政策規範，與本工具無關
  • API 金鑰同樣只存在瀏覽器的 localStorage；按下「送給 AI 生成分析」時，組成的提示詞會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器

使用警語

請注意：
  • 本工具的核心功能是把你的問題組成結構化提示詞；只有主動填入 API 金鑰並按下「送給 AI 生成分析」才會呼叫語言模型，不使用這項功能也能取得組成後的提示詞文字
  • 請勿輸入真實個資、公司機密或不希望被 AI 服務留存的敏感資訊
  • AI 生成的分析可能有誤或過於片面，僅供思考輔助，實際決策請自行查證與判斷，不構成專業建議
  • 使用「送給 AI 生成分析」所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 本工具與創作者不對使用產生提示詞後所得之任何 AI 輸出結果負責
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用
