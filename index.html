換一頂帽子，換一種想事情的方式

填入你正在煩惱的問題，選一頂思考帽或依序戴上六頂，逐步產出結構化分析。免金鑰就能組成提示詞自己貼去用，也可以選填你自己的 AI 金鑰直接取得完整分析結果。

依序模式會固定以「白→紅→黑→黃→綠→藍」的順序各自產出一份分析
①問題主題

用一句話描述你想分析的問題或決策，例如「公司要不要調漲主力產品售價 15%」。

②組成提示詞

純前端組裝，不需要 API 金鑰，可以直接複製貼到任何 AI 對話視窗使用。

③送給 AI 生成分析

選填功能：串接你自己的語言模型 API，直接取得該思考帽視角的完整分析表格。

API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；按下「送給 AI 生成」時，組成後的提示詞會直接傳送給你選擇的服務商官方 API。

④已儲存的分析

把目前主題與產出（含 AI 結果，若有）存成一筆有名字的紀錄，留在這台瀏覽器裡。

使用警語
  • 本工具的核心功能是把你的問題組成結構化提示詞；只有主動填入 API 金鑰並按下「送給 AI 生成分析」才會呼叫語言模型，不使用這項功能也能取得組成後的提示詞文字。
  • 請勿輸入真實個資、公司機密或不希望被 AI 服務留存的敏感資訊——欄位內容只存在你自己瀏覽器的 localStorage，不會上傳到本工具的任何伺服器。
  • AI 生成的分析可能有誤或過於片面，僅供思考輔助，實際決策請自行查證與判斷，不構成專業建議。
  • 使用「送給 AI 生成分析」所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費，也不會經手或保存金鑰。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
